# Noetic hanging rail — client review

Client review preview: https://ahmads-cell.github.io/noetic-hanging-rail-review/

13 real Noetic products with camera-style hanging imagery, SAR price tags, a photographed curved metal rail and a user-controlled looping carousel. Drag horizontally, use the two side arrows or browse with the keyboard. Each dress opens its matching product page directly. The below-rail details panel, dialogs, collection CTA, counters, dots and motion controls have been removed.

The imagery is AI-assisted restaging and still requires owner review for exact garment fidelity. This repository contains only the public review prototype. The editable Shopify implementation is maintained separately in an unpublished review theme; the production storefront theme is unchanged.

Only docs/ is served by GitHub Pages. Private references, theme configuration and source prompts are not included here.

Run `node scripts/check-noindex.mjs` before publishing HTML changes. Every served HTML page, including 404.html, must retain noindex. Noindex is not access control or an absolute search-exclusion guarantee. Site tags cannot control the GitHub UI of this public repository.
